# Texas Truck Parking Inventory

Static dashboard for exploring Texas truck parking inventory.

## Share It Quickly

1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag this entire project folder into the upload area.
3. Share the generated `netlify.app` URL with colleagues.

Keep the HTML file and all PNG files together when uploading. The dashboard must be hosted over `https://`; opening `index.html` directly with `file://` can block the ArcGIS inventory request in the browser.

## GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Settings > Pages**.
3. Set the source to **Deploy from a branch**, select `main` and `/root`, then save.
4. Share the generated GitHub Pages URL.

The project is a static site and does not require a build command or package installation.
